九、踩坑集（前人实测，高复用）
==================================================
1. MyBatis-Plus Map 值参与强转：Set.size() 是 Integer，`(Long)` 强转=ClassCastException 500（本地 mock 单测抓不住）——统一 `((Number)x).longValue()`
2. WXML 不支持 `!(a || []).length` 类复杂表达式，复杂判断放 JS
3. MP 新增 class 必须在页面 wxss 定义（dev-verify static-class 检查）；MP 页面数 sanity band 钉在两处脚本（check-wechat-project-root.sh / check-prototype-state-contract.sh），超 60 需同步调
4. automator：connect 模式无 page.wxml()（用 page.data()）；截图用 mini.screenshot；弹层内元素 tap 可能不派发——用 callMethod 隔离验证
5. Playwright 访问 PC：token 注入 localStorage（key='token'）；SPA 路由等 domcontentloaded+固定等待，勿等 networkidle
6. 本机 curl 走系统代理（12450）会拿缓存响应——验证响应头以服务器本机 curl 为准
7. 后台跑矩阵时 `| tail` 会吃掉 exit code（fail>0 恒 exit 1 是脚本设计）
8. gen-api.py 同时生成 api-list.md 与 .json；矩阵默认排除 logout/switch-group 两端点
9. 读测试库：SQL 写文件→scp→`docker exec -i shared-mysql sh -c 'exec mysql -uroot -p"$MYSQL_ROOT_PASSWORD" db' < file`（sys_menu 列名是 menu_name，无 deleted 列用 status/visible）
