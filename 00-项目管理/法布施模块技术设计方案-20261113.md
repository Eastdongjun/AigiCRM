## 一、模块嵌套方案

法布施作为**独立业务模块**嵌入现有系统，不侵入任何现有模块代码。

```
┌─────────────────────────────────────────────────────────┐
│                    AIGICRM 系统                           │
├──────────┬──────────┬──────────┬──────────┬─────────────┤
│  客户管理  │  四项激励  │  文件管理  │  法布施   │   系统管理    │
│  (现有)   │  (现有)   │  (现有)   │  (新增)   │   (现有)     │
├──────────┴──────────┴──────────┴──────────┴─────────────┤
│              共享底座（不改动）                              │
│  用户/组织/集团 · JWT · 数据字典 · 文件存储+配额 · 审计      │
│  权限矩阵(perm_version) · Flyway · 契约门禁                 │
└─────────────────────────────────────────────────────────┘
```

## 二、数据库设计

### 2.1 字典驱动的数据项（6 个字典类型，不建专用表）

| 字典类型 | 值示例 | 管理入口 |
|---|---|---|
| fabushi_category | 弟子规/了凡四训/论语/道德经/孝经/感应篇/十善业/群书治要/国外类/实用类 | 系统设置→字典管理 |
| fabushi_remind_freq | 每天/工作日/休息日 | 同上 |
| fabushi_section_level | 序/部分/章/节 | 同上 |
| fabushi_badge_type | 首次诵读/连续5天/百次木鱼/读完3本 | 同上 |
| fabushi_znl_tag | 工作心得/人生感悟/美景分享 | 同上 |
| fabushi_edition_type | 原版/译本/注释本/讲义 | 同上 |

> **设计决策**：类别不走专用 fb_category 表——admin 在现有字典管理界面随时增改停，省 4 人天 + 少一张表 + 少一个 PC 页面 + 少两个权限码。

### 2.2 业务表（11 张 `fb_` 前缀）

| 表 | 用途 | 关键字段 |
|---|---|---|
| fb_book | 书目 | id, **category_code**(字典值), title, author, publisher, edition_type(字典), pages, pdf_file_id, status(待审核/通过/驳回/停用), created_by |
| fb_section | 章节结构树 | id, book_id, parent_id, **level_code**(字典), title, sort_order |
| fb_post | 统一内容表 | id, scope_type(heart/recitation/znl), book_id, section_id, user_id, content, group_id, created_at |
| fb_post_attachment | 内容附件 | id, post_id, file_type(image/audio/video), file_id, sort_order, duration_seconds |
| fb_comment | 统一评论 | id, post_id, user_id, type(text/highlight/audio), content, audio_file_id, parent_comment_id |
| fb_read_status | 已读未读 | id, user_id, post_id, read_at |
| fb_user_setting | 个人提醒设置 | id, user_id, reminder_enabled, freq_code(字典), remind_time |
| fb_shelf | 书架 | id, user_id, book_id, status(reading/finished/favorite), last_section_id |
| fb_reading_progress | PDF 阅读进度 | id, user_id, book_id, last_page, total_pages, updated_at |
| **fb_activity** | 共读活动 | id, title, book_id, start_date, end_date, status(active/ended), description, created_by |
| **fb_activity_join** | 活动参与 | id, activity_id, user_id, joined_at |

**统一 fb_post 设计**：心得/诵读/正能量共用一张表（scope_type 区分），评论共用 fb_comment（type 区分），新内容类型只加枚举。

### 2.3 Flyway 迁移（1 个文件）

```
V2026.11.XX.1__fabushi_module.sql
```

内容按序：
1. 建上述 11 张表（utf8mb4_general_ci）
2. `sys_dict_type` 插入 6 个字典类型
3. `sys_dict_data` 插入种子数据（10 类别 + 3 频率 + 4 层级 + 4 徽章 + 3 标签 + 4 版本类型）
4. `sys_menu` 插入：法布施分组 + 3 个页面菜单 + 9 个按钮权限码
5. **禁硬编码 ID**，全部按 permission/dict_type 自然键插入

## 三、权限设计

### 3.1 权限码清单（9 个）

| 码 | 类型 | 含义 | 默认 |
|---|---|---|---|
| fabushi:view | 页面 | 浏览全部内容 | 全员 |
| fabushi:create | 按钮 | 发布/评论/提交书目 | 全员 |
| fabushi:book:view | 页面(PC) | PC 书目管理页 | admin |
| fabushi:book:manage | 按钮 | 书目审核/PDF挂载/停用 | admin |
| fabushi:content:view | 页面(PC) | PC 内容治理页 | admin |
| fabushi:content:manage | 按钮 | 内容下架 | admin |
| fabushi:stats:view | 页面(PC/MP) | 统计看板 | 管理层（PermCenter 勾选） |
| fabushi:stats:export | 按钮 | 导出 Excel | 仅 admin |
| fabushi:activity:manage | 按钮 | 发起/结束共读活动 | admin |

### 3.2 角色默认矩阵

| 角色 | view | create | book:manage | content:manage | stats:view | stats:export | activity:manage |
|---|---|---|---|---|---|---|---|
| admin | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 销售总监 | ✓ | ✓ | — | — | ✓ | — | — |
| 销售/客服/行政 | ✓ | ✓ | — | — | — | — | — |

### 3.3 PermCenter 集成

- 权限码进 FROZEN 登记册（约 113 → 122）
- labelMap 加 9 条中文名
- MatrixTest 加法布施码断言

### 4.3 竞品借鉴的 5 项新功能实现

| # | 功能 | 实现方式 | 人天 |
|---|---|---|---|
| 1 | **周榜重置** | StatsService 查询参数 period=week/month，周榜按 ISO 周一起止聚合 | 0.5 |
| 2 | **部门共读进度** | 聚合查询 sys_dept + fb_read_status，返回 [{deptName, totalUsers, readUsers, pct}] | 1 |
| 3 | **月度阅读报告** | StatsService 新方法：聚合个人当月时长/书目/评论/木鱼数；MP 前端卡片展示（可截屏分享） | 2 |
| 4 | **共读活动** | fb_activity + fb_activity_join 两表；ActivityService 管理生命周期；活动页嵌打卡 + 活动榜 | 3 |
| 5 | **缺卡提醒** | ReminderService 加一条规则：连续 3 天无 fb_read_status 记录 → 应用内提醒 | 0.5 |

## 八、分期交付

| 期 | 内容 | 人天 |
|---|---|---|
| **一期** | 数据库全量 + 字典种子 + 书目/心得/正能量 CRUD + 评论 + MP 12 页 + PC 3 页 + 权限 9 码 + 应用中心入口 | **34** |
| **二期** | 诵读（图/音/视）+ PDF 阅读/进度 + 书架 + 阅读记录 + 统计（含周榜+部门进度+月度报告）+ 导出 + **共读活动** + **缺卡提醒** | **23** |
| **三期** | 语音跟读评论 + 重点描述 + 成就徽章 + 提醒全量 | **10.5** |

**建议首期签约 = 一期 + 二期 = 57 人天**（竞品调研 5 项功能全部包含在二期，法布施的社区感和运营抓手直接到位）。
