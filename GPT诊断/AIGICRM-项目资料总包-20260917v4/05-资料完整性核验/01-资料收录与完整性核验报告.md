## 归档校验与边界

原始上传文件按字节核对通过；源码展开成员与原tar成员的内容核对通过；产品评审ZIP成员CRC核对通过。新总包由生成程序在写出后逐成员读取并检查CRC，同时核对根目录SHA256SUMS的全部相对路径与哈希；如有任何不一致，程序将失败且不得交付该包。

根目录新的SHA256SUMS不包含自身。原始SHA256SUMS以历史原件归档，并未悄悄修写。本次新增总包校验不代表原项目的校验脚本、权限门禁、构建、迁移或业务验收通过。

**交付使用范围：** 内部团队接手资料。因含未改写的源码和历史环境信息，对外发送前应按已批准分享边界复核；D-05仍保留待核对状态。不要将本包描述成已修复源码发布包或可直接生产上线的部署包。

## 复核方法

在解压后的总包根目录，具备相应工具时执行：

```bash
sha256sum -c SHA256SUMS
```

macOS可使用：

```bash
shasum -a 256 -c SHA256SUMS
```

这些命令只核对资料文件字节完整性，不运行项目源码。
