## 1. 系统登录

### 1.1 登录

打开浏览器访问系统地址，进入登录页面。

| 字段 | 说明 |
|------|------|
| 账号 | 输入管理员分配的登录账号 |
| 密码 | 输入密码（新用户默认密码：`123456`） |
| 记住我 | 勾选后下次打开页面自动填充账号 |

点击 **「登 录」** 按钮即可进入系统。

### 1.2 忘记密码

点击登录页面的 **「忘记密码?」** 链接，弹出找回密码对话框，分三步操作：

**第一步：验证账号**
- 输入您的登录账号，点击"下一步"
- 系统会查找您绑定的手机号并脱敏显示（如 `138****0000`）

**第二步：验证身份**
- 选择"手机验证"方式
- 点击 **「获取验证码」**，系统会向您的手机发送6位验证码短信
- 输入收到的验证码，点击"下一步"
- 注意：验证码5分钟内有效，60秒内不可重复获取

**第三步：重置密码**
- 输入新密码（6-30位）和确认密码
- 点击 **「确认重置」**，密码修改成功后重新登录

### 1.3 修改密码

登录后，点击右上角用户头像 → **「修改密码」**：
- 输入原密码、新密码、确认新密码
- 点击"确认修改"，修改成功后自动退出需重新登录

## 2. 工作台（首页）

登录成功后默认进入工作台，展示您最关心的数据概览。

### 2.1 统计卡片

页面顶部展示4张统计卡片：

| 卡片 | 含义 |
|------|------|
| 客户总数 | 您负责的客户总数，以及本月新增数量 |
| 在保护期 | 当前在保护期内的客户数量及占比 |
| 即将到期 | 30天内保护期即将到期的客户数量 |
| 已超期 | 已超过保护期的客户数量 |

### 2.2 快捷入口

6个常用功能快捷按钮，点击直接跳转：
- 新增客户、上传文件、录入激励、待审批、公海捞取、数据统计

### 2.3 图表区域

- **本月新增客户**：按周统计本月新增客户柱状图
- **本月文件上传**：按周统计本月上传文件柱状图

### 2.4 待处理提醒

显示最近5条即将到期或已到期的客户提醒：
- 红色圆点 = 7天内到期（紧急）
- 橙色圆点 = 30天内到期（提醒）
- 点击"全部 →"跳转到提醒管理页面

### 2.5 团队动态

实时展示团队成员的最近操作记录（最多15条），包括：
- 客户跟进、激励上传、文件上传、新增客户、审批提交、系统登录等

### 2.6 待审批

如果有待您审批的事项，会显示在最下方，支持直接 **通过** 或 **驳回** 操作。

## 3. 客户管理

### 3.1 客户列表

**路径：** 客户管理 → 客户列表

#### 筛选功能
- **搜索框**：按客户名称或编号搜索
- **行业筛选**：下拉选择行业类别
- **办事处筛选**：按所属办事处过滤
- **状态筛选**：正常 / 预警 / 超期

#### 数据范围标签
| 标签 | 说明 |
|------|------|
| 全部 | 查看权限范围内的所有客户 |
| 我的客户 | 仅显示您作为第一负责人的客户 |
| 我分享的 | 您分享给他人的客户 |
| 分享给我 | 他人分享给您查看的客户（只读） |

#### 左侧面板
- 显示您的个人信息（姓名、角色、办事处）
- 按行业分类统计客户数量，点击可快速筛选

#### 表格说明
- 点击任意行可进入客户详情页
- **状态列**：正常（绿色）、预警（橙色）、超期（红色）
- **保护措施列**：显示保护期状态（年年持续/开发/预警/超期）
- **操作列**：点击"释放"可将客户释放到公海池

#### 导出
点击右上角 **「导出」** 按钮，下载当前筛选结果的 Excel 文件。

#### 释放客户
点击"释放"按钮后，选择释放原因：
- 保护期满 / 放弃客户 / 离职交接
- 确认后客户将进入公海池，其他人可以捞取

### 3.2 新增客户

**路径：** 客户管理 → 新增客户

填写以下信息后点击"保存"：

| 字段 | 必填 | 说明 |
|------|------|------|
| 订货客户全称 | 是 | 例如：陕煤榆林化学（含二期） |
| 行业 | 是 | 从字典选择 |
| 开发类型 | 是 | 从字典选择 |
| 所属办事处 | 是 | 选择客户所属区域 |
| 第一负责人 | 是 | 选择主要负责的销售人员 |
| 所属集团 | 否 | 客户所属集团名称 |
| 所属分公司 | 否 | 分公司名称 |
| 所属单位 | 否 | 具体单位 |
| 产能（万吨） | 否 | 客户产能规模 |
| 省/市/区 | 否 | 客户地理位置 |
| 厂址 | 否 | 详细地址 |
| 注册日 | 否 | 客户注册/首次合作日期 |
| 最近开票日 | 否 | 最近一次开票日期 |
| 备注 | 否 | 补充说明 |

> **编号规则**：系统根据"系统设置 → 编号规则"自动生成客户编号（如 NM-202606-001）。

> **保护期**：系统自动计算到期日 = 注册日/开票日 + 保护天数（默认360天，可在系统设置中修改）。

### 3.3 客户详情

**路径：** 点击客户列表中的任意客户行

详情页分为以下区域：

#### 头部卡片（蓝色）
- 显示客户名称、行业、负责人
- 核心客户/非核心客户标识
- 到期日期和保护状态

#### 积分栏
- 激励积分（四项激励累计）
- 客情关系（商务关系评分）
- 综合得分（两者相加）

#### 基本信息 & 组织信息
- 两列展示客户的行业、开发类型、办事处、负责人、产能
- 以及集团、分公司、单位、地址等组织信息

#### 保护期状态
- 显示注册日、最近开票、到期日、当前状态
- 点击 **「申请延期」** 可发起保护期延长审批

#### 客情 · 商务关系深度
- 四个档位可选：商务少(0分)、纯商务(1分)、感情商务(2分)、多样性(3分)
- 点击即可保存评分

#### 开票记录
- 查看历史开票记录
- 点击 **「+ 录入开票」** 添加新的开票记录
- 填写：开票日期、发票号码、发票类型、开票单位、金额（万元）

#### 核心客户六项指标
- **第1项**：开票回款（硬性门槛 ≥ 100万）——系统自动判定
- **第2-6项**：通过下拉选择评分
  - 高层客情程度
  - 渠道编码数量
  - 基层分厂车间覆盖
  - 产品品类覆盖
  - 项目资金/类型
- 总分 ≥ 12 且开票 ≥ 100万 → 判定为 **核心客户**
- 点击"保存"提交指标评分

#### 跟进日志
- 在输入框中填写跟进记录，点击 **「记录」** 提交
- 下方以时间线形式展示历史跟进记录

#### 分享客户
- 点击右上角 **「分享」** 按钮
- 选择要分享的用户（可多选），对方将获得该客户的只读查看权限

> **注意**：从公海池进入的客户详情为 **只读模式**，不可编辑、不可分享、不可录入数据。

## 4. 文件管理

**路径：** 文件管理

### 4.1 文件分类

页面顶部有4个标签页：

| 标签 | 说明 |
|------|------|
| 公共 | 所有人可见的公共文件 |
| 私人 | 仅自己可见的私人文件，占用个人存储配额 |
| 四项激励 | 通过激励模块上传的文件 |
| 分享给我 | 他人分享给您的文件（只读） |

### 4.2 文件夹管理

左侧面板显示文件夹列表：
- 点击文件夹名称可筛选该文件夹下的文件
- 点击 **「新建文件夹」** 创建新文件夹
- 私人标签页下方显示个人存储空间使用情况

### 4.3 上传文件

点击右上角 **「上传」** 按钮，弹出上传对话框：
- 支持拖拽上传或点击选择文件
- 支持批量上传多个文件

### 4.4 文件操作

每个文件右侧有操作按钮：
- **下载**：下载文件到本地
- **分享**：分享给其他用户（只读权限）
- **删除**：删除文件（公共文件仅管理员可删除）

## 5. 四项激励Plus版

### 5.1 激励上传

**路径：** 四项激励Plus版 → 激励上传

#### 操作步骤

1. **选择周期**：在顶部选择评估周期（如"2026上半年"）
2. **选择大类**：点击四个激励大类标签之一（如"访问类"、"交流类"等）
3. **选择子项**：在左侧面板点击具体的激励子项旁边的 **「上传文件」**
4. **关联客户**：在弹窗中搜索并选择关联的客户
5. **设置共享**：选择是否共享给团队
6. **上传文件**：选择文件上传（支持 PDF、Word、Excel、图片，≤ 50MB）

#### 已上传文件

右侧表格展示已上传的文件记录：
- 支持按大类、档位筛选
- 支持文件名搜索
- 可点击客户名跳转到客户详情

### 5.2 激励统计

**路径：** 四项激励Plus版 → 激励统计

页面顶部显示4张概览卡片：激励事项数、可共享项数、本周期文件数、总积分。

三个标签页：

#### 激励统计表
- 按大类分组展示每个子项的积分、上传数量、总积分
- 底部合计行汇总所有数据

#### 个人排行
- 按总积分降序排列所有人员
- 显示：排名、姓名、办事处、总积分、上传数
- 前三名显示金银铜奖牌

#### 部门排行
- 按部门汇总积分
- 显示：排名、部门名称、总积分、参与人数、人均积分

## 7. 公海管理

### 7.1 公海池

**路径：** 公海管理 → 公海池

公海池是存放未被认领客户的"资源池"。

#### 统计卡片
- 池内待捞、本月入池、待审批捞取、本月成功捞取

#### 状态标签
- 全部 / 待捞取 / 审批中 / 已捞取

#### 筛选条件
- 行业、进入原因（保护期满/放弃客户/离职交接）、客户名称

#### 捞取客户
1. 在列表中找到目标客户
2. 点击 **「捞取」** 按钮
3. 确认后系统自动发起审批申请
4. 审批通过后客户将分配给您

#### 查看客户详情
- 点击客户名称可查看客户详情（只读模式，不可编辑）

### 7.2 捞取记录

**路径：** 公海管理 → 捞取记录

查看所有捞取申请的历史记录：
- 可按日期范围、审批状态、关键词筛选
- 显示：申请日期、客户名称、行业、捞取人、审批人、状态、审批时间

## 8. 审批管理

**路径：** 审批管理

管理所有客户资源相关的审批流程。

### 审批类型

| 类型 | 说明 |
|------|------|
| 捞取 | 从公海池捞取客户的申请 |
| 转让 | 客户在人员之间转让的申请 |
| 延期 | 客户保护期延长的申请 |
| 入库 | 客户入库/存储申请 |

### 标签页
- **待审批**：需要您审批的事项（显示数量角标）
- **我发起的**：您提交的审批申请
- **审批中**：正在流转中的审批
- **已通过 / 已驳回**：历史审批记录
- **全部**：所有审批记录

### 审批操作
在"待审批"标签下：
- 点击 ✓（绿色）**通过** 审批
- 点击 ✗（红色）**驳回** 审批，需填写驳回原因

## 9. 统计分析

**路径：** 统计分析

全局数据分析看板，支持按年份和办事处筛选。

- **年份**：2024 ~ 2030年

- 表格展示各办事处的客户数、本月新增、活跃率

#### 月度图表
- 月度新增客户柱状图（1-12月）

## 10. 积分管理

### 10.1 积分录入

**路径：** 积分管理 → 积分录入

1. 选择 **评分周期**（年份 + 上/下半年）

3. 点击单元格直接输入分数（必须在该行设定的区间范围内）
4. 点击 **「+」** 添加新的同事列
5. 点击 **「保存」** 提交所有评分
6. 点击 **「导出」** 下载评分表 Excel

### 10.2 积分排行

**路径：** 积分管理 → 积分排行

展示所有人员和部门的积分排行。

#### 概览卡片
- 参与人数、参与部门、最高积分、文件总数

#### 个人排行
- 按总积分降序排列
- 显示：排名、姓名、办事处、总积分、文件数、趋势
- 前三名显示奖牌图标

#### 部门排行
- 按部门汇总积分
- 显示：排名、部门、总积分、参与人数、人均积分

## 12. 系统管理（仅管理员）

> 以下功能仅管理员角色可见。

### 12.1 人员管理

**路径：** 系统管理 → 人员管理

#### 查看人员
- 支持按关键词、部门、状态筛选
- 表格显示：账号、姓名、手机号、邮箱、部门、办事处、角色、状态、存储空间、创建时间

#### 新增用户
点击 **「新增用户」** 按钮，填写：

| 字段 | 必填 | 说明 |
|------|------|------|
| 账号 | 是 | 登录用户名，不可重复 |
| 姓名 | 是 | 真实姓名 |
| 手机号 | 是 | 用于忘记密码时验证身份 |
| 邮箱 | 否 | 选填，格式校验 |
| 部门 | 是 | 选择所属部门 |
| 办事处 | 是 | 选择所属办事处 |
| 角色 | 是 | 选择用户角色 |
| 状态 | — | 开关：正常/禁用 |

> 新用户默认密码为 `123456`，用户首次登录后建议修改。

#### 重置密码
在操作列点击"重置密码"，将用户密码重置为 `123456`。

### 12.2 组织架构

**路径：** 系统管理 → 组织架构

管理公司的组织树形结构。

#### 部门类型
| 类型 | 说明 |
|------|------|
| 总部 | 顶级组织（1个） |
| 大区 | 区域分组（如华北大区） |
| 办事处 | 最小业务单元（如内蒙办、太原办） |

#### 操作
- **新增部门**：选择上级部门、填写名称、类型、负责人、排序
- **编辑**：修改部门信息
- **添加子部门**：在当前部门下创建下级部门

### 12.3 系统设置

**路径：** 系统管理 → 系统设置

包含4个配置标签页：

#### 基本设置

| 配置项 | 说明 |
|--------|------|
| 系统名称 | 显示在侧边栏和登录页的系统名称 |

#### 字典管理
管理系统中的下拉选项数据：
- **左侧**：字典类型列表（如行业、开发类型等）
- **右侧**：选中类型后编辑具体的字典数据项
- 支持新增、编辑、删除字典类型和数据

#### 公海配置
管理公海池的划分：
- 设置公海池名称
- 配置包含的办事处区域
- 配置可见角色

#### 激励类别
管理四项激励的类别树形结构：
- 顶级类别（大类）：如访问类、交流类、计划类、试用类
- 子类别（子项）：具体的激励细分项
- 每个子项可设置分值
- 支持新增、编辑、删除、添加子类别

## 13. 常见问题

### Q1：忘记密码怎么办？
在登录页面点击"忘记密码?"，通过手机短信验证码重置密码。如果手机号未绑定，请联系管理员重置密码为 `123456`。

### Q2：为什么看不到某些菜单？
系统根据您的角色权限显示菜单。如需更多权限，请联系管理员在"人员管理"中调整您的角色。

### Q3：客户保护期是怎么计算的？
保护期 = 注册日（或最近开票日，取较晚者）+ 保护天数（默认360天）。到期前30天系统会显示预警提醒。

### Q4：什么是核心客户？
同时满足两个条件的客户：
1. 累计开票金额 ≥ 100万元
2. 六项指标总分 ≥ 12分

### Q5：公海池的客户怎么来的？
三种途径进入公海：
1. 保护期满自动释放
2. 负责人主动放弃客户
3. 人员离职交接释放

### Q6：如何修改系统Logo和名称？
管理员进入 "系统管理 → 系统设置 → 基本设置"，修改系统名称或上传新Logo后保存即可。

### Q7：上传的文件大小有限制吗？
单个文件最大 100MB。私人文件占用个人存储空间（默认10GB），公共文件不占用个人配额。
