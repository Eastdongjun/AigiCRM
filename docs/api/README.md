# API 接口契约约定

> 接口是前后端与跨模块的契约,改动必须按本文约定执行。

## 规则

1. **接口先行**: 新功能先定义接口(路径/方法/参数/返回/权限码),再开发前后端
2. **改动必更新清单**: 接口增删改后,运行 `scripts/gen-api.py` 重新生成 `api-list.md` 并提交
3. **权限码对应**: 每个受保护接口必须有 @PreAuthorize(权限码来自 sys_menu,见 permission-dict.md)
4. **新增接口清单**:
   - [ ] 控制器加 @PreAuthorize
   - [ ] sys_menu 加权限码行 + 角色绑定
   - [ ] 重新生成 API 清单 + 权限字典
   - [ ] 冒烟测试回归(如属核心链路)
5. **破坏性变更**(改路径/删参数/改返回结构)必须:
   - 在交付报告标注"接口不兼容变更"
   - 检查所有调用方(前端/其他模块)
