# 任务卡模板

> 每个开发任务按此模板拆解(一个任务 = 一个目标)。配合功能包使用,功能包管交付,任务卡管开发单元。

````markdown
# TASK-XXX 任务名

## 目标
<!-- 一句话: 完成什么, 解决什么 -->

## 业务背景
<!-- 为什么做, 关联需求 REQ-### -->

## 包含范围
- [ ] <!-- 功能点 -->

## 不包含范围
- <!-- 明确排除 -->

## 验收标准
- [ ] <!-- 可测试条件, 对应 AC-### -->

## 数据/接口/权限影响
- 数据库: <!-- 表/字段/迁移脚本 -->
- 接口: <!-- 路径/方法/权限码 -->
- 权限: <!-- 权限码/角色 -->

## 测试计划
- 单元测试: <!-- 覆盖点 -->
- 冒烟回归: <!-- 涉及链路 -->
- 异常/边界: <!-- 场景清单 -->

## 验证命令
```bash
# 后端
cd aigicrm-backend && mvn test
# 前端
cd aigicrm-ui && npm run build
# 回归
scripts/smoke-test.sh prod
```

## 风险
- <!-- 越权/数据/兼容/性能 -->

## 回滚方式
- <!-- git revert 或 rollback.sh 路径 -->
````
