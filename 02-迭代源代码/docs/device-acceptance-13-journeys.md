### J12 Redis 故障 fail-closed(可选,需演练窗口)

> 破坏性测试,只打测试服;窗口内测试服所有会话受影响,建议独占时段执行。命令在 Mac 终端跑,执行前后各截一次小程序表现。

| 步骤 | 端 | 操作 | 预期/通过标准 | 结果 |
| --- | --- | --- | --- | --- |
| 1 | Mac | `ssh aigicrm-test 'docker ps --format "{{.Names}}"'` 找到 redis 容器名并 `docker stop <redis>` | 容器停止 |  |
| 2 | 小程序 | 已登录会话继续操作;另一设备尝试**新登录** | 权限判定路径 fail-closed:拒绝/503,**不得放行未鉴权数据**;登录失败有明确报错而非静默 |  |
| 3 | Mac | `docker start <redis>` | 容器恢复 |  |
| 4 | 小程序 | 重试登录与操作 | 自动恢复正常,无需重装 |  |
