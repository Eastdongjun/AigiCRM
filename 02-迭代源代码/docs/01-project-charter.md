# 项目章程(AIGICRM 客户管理系统)

> 历史项目快照(2026-08-02 补记)。本文回答"系统为什么存在、边界在哪、怎么算成功"。

## 一、项目背景与痛点

- 背景:艾志(南京)环保管接技术股份有限公司销售体系(山西/河北/内蒙古三办)的客户资源与激励管理。
- 痛点:客户归属/保护期靠线下,激励申报无统一平台,审批靠线下签字,数据分散。

## 二、项目目标

- 客户资源统一管理(归属/保护期/公海/审批)
- 四项激励线上化(产品试点/两谈两做/交流拜访/外出参观)
- 学分与六项指标考核
- 数据可统计、可审计、可回溯

## 三、目标用户与角色

| 角色 | 说明 |
|---|---|
| 系统管理员 | 全部权限 |
| 行政 | 管理类权限 |
| 销售总监 | 管理+销售,全组织数据 |
| 销售员 | 业务权限,本组织及下级数据 |

## 四、建设范围

**本期实现**:客户管理/文件管理/四项激励/提醒/公海/审批/学分/六项指标/统计分析/系统管理(用户/角色/岗位/组织/字典/权限/配置/日志)。

**本期不实现**:独立 App / AI 预测 / 多语言 / 海外部署 / 复杂数据中台 / 移动端(仅 PC 浏览器)。

## 五、成功指标

- 客户/激励/审批全流程线上化(无线下台账)
- 每日健康检查 200,数据每日备份
- 发布有脚本/回滚有预案/问题有复盘

## 六、关键约束

- 生产数据唯一权威(生产→测试单向同步)
- 部署环境:生产 39.99.35.218 / 测试 111.229.37.220
- 存储:数据盘(业务数据)+ NAS(前端/备份)+ 系统盘(程序)
- 验收负责人:用户(老板)

## 七、主要风险与应对

| 风险 | 应对 |
|---|---|
| 数据丢失 | 每日备份 NAS + 双副本 |
| 越权/数据泄露 | 权限矩阵 + 独立安全审查 + 越权测试 |
| 发布事故 | 演练 + 备份 + 一键回滚 + 门禁 |
| 知识流失(单人维护) | 知识资产文档化 + 交付机制 |
