# 客户生命周期与保护期

> 来源锚点:`CustomerExpireTask`(每日凌晨 2 点任务)、`ApprovalService.applyApprovalAction`(审批执行)、`CustomerService`(创建/更新/公海)。核实日期 2026-09-24。

## 1. 状态机

```
normal(正常) → warning(临期,≤30天) → expired(到期) → sea(公海池内)
                    ↑ 延期审批通过可回到 active/normal                    ↓ 捞取审批通过 → normal(新负责人)
                                                          archived(归档,不参与统计/提醒/到期检查)
                                                          deleted=1(软删)
```

- 归档与公海客户**不参与**统计、提醒、到期检查(2026-09-22 B5 统一口径)。
- 软删不物理删除,列表按 deleted=0 过滤。

## 2. 创建与归属

- 创建时客户归属部门自动=负责人部门(`syncCustomerDeptId`);负责人无部门时显式清空,不残留旧部门。
- 集团归属由租户拦截器按 tenant_id 管理,实体无此字段。
- 客户编码自动生成;行业/开发类型走字典(`成熟创新`/`突破开拓`/`铺垫宣传`/`新建改建扩建大修`,最后一项是一个完整分类词,**不可拆分**)。

## 3. 保护期与到期日(唯一公式)

```
到期日 expire_date = 基准日 + customer.protection.days(360) + approved_extend_days(累计已批延期)
基准日 = COALESCE(最近开票日, 注册日);两者皆空 → 延期时以当天起算
```

- 开票记录增删会**回算开票推导部分**,但**不收回**已批延期(累计延期独立叠加)。
- **注册日与最近开票日**录入后,仅 总监(角色 0)+ 行政(角色 05)+ admin 可修改(V2026.09.23.2 绑定对齐)。

## 4. 延期流程

提交 extend 审批 → 审批通过 → `approved_extend_days += customer.extend.days`(默认 360)→ 按唯一公式重算到期日 → 状态回到 active/normal。见 [approval.md](approval.md)。

## 5. 每日凌晨检查(2:00,CustomerExpireTask)

逐客户隔离(单条脏数据/唯一键冲突不中断整批,失败记 error 作告警钩子):

| 情形 | 动作 |
| --- | --- |
| 已到期(≤今天) | protection_status=expired、status=expired;**若办事处配置了公海池则入池**(无池配置保持 expired——防 pool_id=NULL 孤儿行,普通用户不可见也捞不了) |
| 30 天内到期 | protection_status=expiring、status=warning;物化一条 expiring 待办提醒(去重规则见 [reminder.md](reminder.md)) |

## 6. 公海池

- 池按**办事处**配置(matchSeaConfig);同一办事处无配置则不自动入池,手动释放同理。
- **释放**:负责人手动,客户进入所在办事处公海池(可见性按池级权限)。
- **捞取(claim)**:池内 available 状态可申请 → 提交审批 → **原子锁**(条件更新 status available→pending_approval,并发双捞只有一方成功)→ 审批通过 owner 变更为申请人、移出池。
- **删除**:仅 available 状态且持 `sea:pool:delete`;池编辑(`sea.edit`)不改属主/状态,防池编辑者自领绕过捞取审批。

## 7. 转移(2026-09-19 PR-09 上线,09-24 补 fail-fast)

```
PC 客户详情「转移客户」→ 选接收人(候选=当前集团成员,排除现任负责人)
  → 提交 transfer 审批【提交即校验:接收人在册/启用/未删 + 同集团(admin 豁免跨集团)——
     不满足当场报错,不留"已提交却永远无法生效"的单据】
  → 审批人批准 → owner=接收人、客户部门同步=接收人部门、transfer_date=当天
```

- 接收人校验在**提交时与审批执行时双重把关**,口径逐字一致。
- 小程序端可查看/审批转移类单据,**发起入口仅 PC**。

## 8. 分享

- 即时生效,无需审批;一个客户可分享多人;接收人获得该客户可见性(读)。
- 分享/转移**接收人下拉=当前集团成员**(与数据范围无关,2026-09-23 修正:原按数据范围过滤致跨团队合法转移选不到人)。

## 9. 编辑边界

- 公海池内客户禁止经编辑接口改属主/状态(只能走捞取/释放流程)。
- 非池客户的负责人变更:非 admin 只能走转移审批,直接编辑被拒。
