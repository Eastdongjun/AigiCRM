# AIGICRM 数据字典:组织对象与数据范围语义

> **版本**:2026-09-19 · **依据**:总册 PR-15 + 源码核验 · **代码**:DataScopeType.java + BizCustomer.java
> **用法**:本文件是组织对象与数据范围的权威定义;任何修改须走业务决策会。

---

## 1. 四类组织对象

| 对象 | 字段(客户表) | 含义 | 与租户边界的关系 |
|---|---|---|---|
| **业务集团** | `sys_group`(会话集团) | 登录用户所属的**数据隔离边界**(tenant_id);一个用户可属多集团,会话选定一个 | **就是**租户边界——跨集团读写被拦截器+PR-01 家族封锁 |
| **客户所属集团** | `groupName`(String) | 客户的**企业关系属性**——该客户属于哪个企业集团(如"陕煤集团"),与登录集团的隔离边界无关 | **不是**租户边界;是客户画像字段,用于业务分组与搜索 |
| **法人/分公司** | `branchCompany`(String) | 客户的法人实体或分支机构名称(如"邯钢集团邯宝钢铁有限公司") | 纯客户属性;多个法人可属同一企业集团 |
| **现场单位/厂矿** | `unitName`(String) | 具体作业现场或工厂矿山名称(如"邯宝钢铁炼铁厂") | 纯客户属性;一个法人下可有多个厂矿 |

**关键区分**(总册 F12):修改客户的 `groupName` **不会**改变系统租户归属;两者是独立概念。

## 2. 数据范围(DataScope)语义

| 范围 | 代码 | 含义 | 典型角色 |
|---|---|---|---|
| **self** | `self` | 仅本人创建/负责的数据 | 销售员 |
| **team** | `team` | 本人及下属(按汇报线) | 团队主管 |
| **office** | `office` | 本办事处及以下全部 | 办事处主任 |
| **dept** | `dept` | 本部门及以下(部门树) | 部门经理 |
| **all** | `all` | 当前集团全量(**非跨集团**) | 集团管理员 |
| **custom** | `custom` | 自定义(按 sys_user_org/sys_role_org 指定) | 特殊岗位 |

**关键区分**(总册 PR-15):
- `team` ≠ 部门——team 按**人员汇报线**(我及我的下级),dept 按**组织树**(本部门及子部门);
- `office`/`region` ≠ 客户地理省市——它们是**销售组织的层级**(办事处/大区),不是客户所在的行政区划;
- `all` 在多集团部署下=当前会话集团的全量,平台 admin 才是跨集团全量(P1-09 裁决口径)。

## 3. 锚点角色区分

| 角色 | 含义 | 典型字段 |
|---|---|---|
| **负责人(owner)** | 客户的当前责任人(保护期归属、业绩归属) | `ownerId` |
| **创建人(creator)** | 录入该记录的用户(可能=owner,也可能代建) | 日志/审批的 `applicantId` |
| **上传人(uploader)** | 上传附件的用户(激励记录的 `userId`) | `biz_incentive_record.userId` |

三者不可混用:转移客户只改 `ownerId`,历史创建人和上传人保留(总册 PR-09"保留历史作者")。

## 4. 字段命名规范

| 概念 | 统一命名 | 禁止混用 |
|---|---|---|
| 业务集团(租户) | `groupId` / `tenantId` | ~~orgId~~(歧义) |
| 客户所属集团 | `groupName` | ~~groupId~~(与租户混淆) |
| 办事处 | `officeId` | ~~orgId~~ |
| 大区 | `regionId` | ~~areaId~~ |
| 部门 | `deptId` | — |
| 负责人 | `ownerId` | ~~userId~~(歧义) |
