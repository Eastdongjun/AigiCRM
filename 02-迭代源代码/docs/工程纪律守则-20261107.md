# 工程纪律守则（2026-11-07）

> 出处：`out/项目复盘-错误清单-20261107.md`（四路取证 25 条错误 / 14 高危）。
> 复盘顶层结论：**"绿了"不等于"对了"；删除没有铁律；做完不等于修完；形态改动不动工先确认。**
> 本守则把这些教训收敛为 12 条铁律，每条配两层执法：
> **机器执法** = `scripts/check-discipline-gates.sh`（已登记进 `dev-verify.sh contracts`，每次提交前自动跑）+ 既有契约；
> **人工执法** = 改码/部署前对号自查（与《变更八法检查单》配合使用）。
> 修订权限：本文件只能经用户令修订；任何豁免必须书面登记在文末台账，不留口头豁免。

## 与既有纪律的关系

- 《变更八法检查单》（2026-11-01 用户令立）管"一次变更怎么改"；本守则管"哪些错误永远不再犯"。两者在 T3/T5/T9 上重叠，重叠处以更严者为准。
- 既有 85 个 check-* 契约 = 各领域防复活钉；本守则的 `check-discipline-gates.sh` 是横切层，不替代它们。
- 复盘报告里的"verified / unconfirmed"不是本守则的验收口径；本守则的验收口径 = 门禁跑绿 + 台账划销。
