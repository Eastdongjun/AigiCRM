# AIGICRM PC-Mobile Unified Development Todo List

Date: 2026-09-06

## 1. Delivery Goal

Build AIGICRM as one unified CRM product across PC and WeChat Mini Program:

- Same backend APIs.
- Same database.
- Same account, role, position, permission and data-scope model.
- Same business workflows and audit path.
- Different page presentation only.
- Local deployment and local testing first.
- No production push or production deployment in this phase.

## 2. Global Completion Definition

Each module is complete only when all items below are satisfied:

- PC page behavior is mapped.
- Mini Program page behavior is mapped.
- Backend API is identified or added.
- Permission code is identified or added.
- Role and position access is defined.
- Data-scope rule is defined and enforced server-side.
- Button visibility is frontend-only UX and never the final security boundary.
- Business workflow start, process and end states are documented.
- Statistics or derived values have explicit calculation inputs.
- Tests or manual QA checklist exists.
- Local build/test passes.
- Sonar issues are checked.
- Production deployment is not performed.
