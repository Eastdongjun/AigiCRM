## 0. 环境与账号准备

- [ ] 微信开发者工具已导入 `02-迭代源代码/aigicrm-miniprogram`（目录直接含 `app.json`、`project.config.json`）。
- [ ] `config/env.local.js` 指向测试环境：`apiBaseUrl: 'http://111.229.37.220'`、`demoMode: false`。
  - 裸 IP + HTTP 仅开发者工具/预览可用；体验版/正式版必须 HTTPS 合法域名。
- [ ] 工具 → 清除缓存 → **清除全部**，然后重新登录，避免旧权限/旧菜单缓存。
- [ ] 准备至少 4 类账号（记录角色/权限组合即可，不记录密码）：
  1. `admin`（系统管理员）
  2. 普通销售（self 范围、基础权限）
  3. 组织管理员（如同一账号有 orgAdmin）

- [ ] PC 端同步打开权限中心，方便“改权限 → 小程序生效”对照。
- [ ] 后端健康：`/actuator/health` 200；前端首页 200。

## 7. 判定标准

- **PASS**：所有 P0/P1 项通过；允许项 200、拒绝项 403；PC/MP 数据一致；无白屏/无越权。
- **FAIL**：任一项出现“无权限仍可访问/有权限被误拒/数据范围越界/入口与接口不一致”。
- **BLOCKED**：环境/账号/数据缺失导致无法验证，需记录原因，不能算通过。
