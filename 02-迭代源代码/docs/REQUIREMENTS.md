# AIGICRM 需求总册(中文)

> 版本 2026-09-24。本册是**全部需求的收拢入口**:业务背景→角色→功能全景→业务流程→规则数值→未决事项。分层阅读:本册=索引与摘要;[unified-feature-manifest.md](unified-feature-manifest.md)=功能/权限逐条清单;[business/](business/README.md)=流程与规则细节(每篇标注代码来源锚点)。历史英文版 blueprint(09-15)由本体系取代,留档 git。

## 1. 业务背景

艾志(南京)环保管接技术股份有限公司销售体系(山西/河北/内蒙古三办事处)的客户资源与激励管理。核心诉求:

- 客户资源公司化:负责人制+保护期+公海回收,防客户随人走;
- 四项激励的佐证化管理:成熟创新/突破开拓/铺垫宣传/新建改建扩建大修,记录带安装前/中/后文件佐证,分享制传阅;
- 三端一致:PC(Web)与微信小程序共用后端/账号/权限/数据,仅界面形态不同;
- 集团多租户隔离(fail-closed:无归属=不可见)。

## 2. 角色与授权体系

| 角色 | 语义 | 数据范围默认 |
| --- | --- | --- |
| admin(系统管理员) | 平台超管,豁免租户/集团边界 | all |
| 0 销售总监 | 业务管理 | custom(自定义组织集) |
| 05 行政 | 行政管理(持系统用户管理等敏感码) | office |
| 06 销售员 | 一线 | team |

叠加三条独立授权轴:①用户级数据范围 override;②组织管理员 orgAdmin(按组织管人,**不可操作 admin 账号**);③激励授权面板(按人四开关:查看分享/查看全部/编辑/删除他人记录)。新角色可经角色管理自建。

## 3. 功能全景(按模块,详见 manifest 逐条)

- **客户**:增删改查/高级筛选/导入导出;详情含联系人/财务/跟进/时间线/六项指标/客情评分;转移(审批制)/分享(即时)/释放入海。
- **待办任务**:本人任务列表/统计,管理方创建/完成/取消;工作台角标联动。
- **文件中心**:文件夹树+ACL;上传/替换/删除/分享;按人 10GB 配额;匿名公开下载通道(仅静态资源)。
- **激励(四项激励)**:分类树浏览/上传佐证/查询(分享制)/已读跟踪/统计三视图(统计表/客户排行/个人排行)/阅读统计与排行榜;记录编辑/删除按授权面板。
- **提醒**:六类(到期/开票超期/从未开票/三类分享);到期提醒每日物化跟进。
- **审批**:捞取/延期/转移/配额四类动作;配置流(串行阶段/或签会签)优先,兜底角色+直属领导。
- **公海**:按办事处配置池;释放/捞取(审批+原子锁)/池删除/池配置(PC)。
- **统计**:工作台仪表盘/统计页/积分排行页(客户排行三类口径)/指标页。
- **积分**:积分项定义/批量录入(Excel)/网格/公司级排行(**与激励分是两套体系**)。
- **系统管理**:用户/角色/岗位/组织/配置/字典/日志(均 PC)。

## 5. 关键规则数值(生产现值)

保护期 360 天 / 临期窗口 30 天 / 延期一次 +360 天 / 开票超期 365 天 / 登录限流 5 次(用户名)·20 次(IP)·锁 15 分钟 / 文件配额 10GB 每人 / 审批直属领导向上最多 5 层 / team 范围深度 ≤5。完整表见 [business/README.md](business/README.md)。
