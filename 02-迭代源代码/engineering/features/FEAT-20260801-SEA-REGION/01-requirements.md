# 需求规格

## 目标用户与场景

- 管理员在系统设置→公海配置→新增/编辑公海池，勾选可见范围（组织架构树）
- 管理员查看组织架构页，类型以中文显示

## 事实

- 公海池可见范围 = visibleDeptIds + visibleUserIds；regionIds 用于客户释放路由（办事处维度）
- 组织架构 dept_type：1 总部/2 大区/3 办事处/4 部门；sys_org.org_type 同为数字

## 假设

- 总部不允许选（组织根节点，选中无业务意义）

## 阻断问题

无

## 功能需求

| 需求 ID | 描述 | 来源 | 优先级 |
|---|---|---|---|
| REQ-001 | 公海池可见范围树：大区/办事处/部门/人员均可勾选，仅总部灰显 | 用户输入 | Must |
| REQ-002 | 勾选/取消/清空/编辑回显完整可用（修复缺失函数） | 用户输入+实测 | Must |
| REQ-003 | 保存大区后：大区下部门用户对该池可见（isVisibleTo 上溯）；regionIds 派生大区子树办事处 | 用户输入 | Must |
| REQ-004 | 组织架构页类型列显示中文（1总部/2大区/3办事处/4部门），新增表单类型下拉为数字值 | 用户输入 | Must |

## 业务规则与权限

- 总部(1)灰显不可选；check-strictly 独立勾选（选大区不自动选子级）
- 办事处分池互斥校验（checkOfficeOverlap）保持

## 异常与边界

- visibleDeptIds 含已删除部门：isVisibleTo 上溯到空即不可见（安全）
- 大区无 type=3 子级：regionIds 为空（无释放路由影响）

## 非功能需求

- 兼容：check-strictly 模式不变；性能：isVisibleTo 每次加载 dept 全表（池数量少，可接受）

## 验收标准

|验收 ID | 对应需求 | Given / When / Then |
|---|---|---|
| AC-001 | REQ-001 | Given 新增公海池弹窗，When 打开组织架构树，Then 山西大区/太原办销售部/太原办行政部/人员均可勾选，总部灰显 |
| AC-002 | REQ-002 | Given 弹窗勾选大区+办事处+部门，When 查看"已选范围"，Then 标签显示对应名称；编辑已有池时树回显勾选 |
| AC-003 | REQ-003 | Given 勾选山西大区(2)+太原办销售部(4)+太原办行政部(5)保存，Then 数据库 visible_dept_ids=2,4,5 且 region_ids=4（大区派生办事处） |
| AC-004 | REQ-004 | Given 组织架构页，When 打开，Then 每行类型显示 总部/大区/办事处/部门 中文 |

## 追踪关系

- REQ-001~003 → AC-001~003；REQ-004 → AC-004
