# 功能受理

## 用户目标

系统设置→字典管理页面 UI 美化："要好看 合理 经典布局"。

## 当前行为

- 字典管理为左右两栏（左侧字典类型表格 + 右侧字典数据表格），灰底 (#fafbfd) 朴素风格，无空态引导、无选中视觉反馈强化、操作按钮常显拥挤

## 范围

- config.vue 字典管理 Tab：左侧类型表格 → 卡片列表（图标+名称+内置tag+编码+悬浮操作）；右侧数据区白卡片 + 数据条数 tag + 空态引导（未选类型）；图标补 import；样式重写
- 功能零改动（新增/编辑/删除弹窗、数据加载逻辑保持）

## 不在范围

- 生产部署（需授权）；其他 Tab 美化

## 来源与事实

- 用户输入："字典管理 页面UI美化 要好看 合理 经典布局"
- 基线截图 evidence/ui-baseline-1440x900.png（改前）

## 约束

- 测试服；纯前端改动

## 初始风险

- 低：纯视觉重构，功能逻辑未动
