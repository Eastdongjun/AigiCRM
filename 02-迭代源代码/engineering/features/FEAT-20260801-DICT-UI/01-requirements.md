# 需求规格

## 目标用户与场景

- 管理员维护字典（类型+数据）；字典管理页需清晰高效：类型一目了然、选中状态明确、未选时有引导

## 事实

- 左侧 11 个字典类型（dev_type 等，多为内置）；右侧数据按类型加载
- 原布局灰底表格、无空态、选中反馈弱

## 假设

- 经典布局 = 左列表右详情、白卡片、选中高亮、空态引导

## 阻断问题

无

## 功能需求

| 需求 ID | 描述 | 来源 | 优先级 |
|---|---|---|---|
| REQ-001 | 左侧字典类型改为卡片列表：名称+编码+内置tag+悬浮操作，选中高亮蓝边 | 用户输入 | Must |
| REQ-002 | 右侧数据区白卡片化：类型名+数据条数tag+新增按钮，未选类型时空态引导 | 用户输入 | Must |
| REQ-003 | 全部既有功能保持（新增/编辑/删除/选中加载） | 用户输入 | Must |

## 业务规则与权限

- 无变化；内置类型不可删（原逻辑）

## 异常与边界

- 无类型时左侧显示 el-empty
- 未选类型时右侧空态引导且新增禁用

## 非功能需求

- 视觉评分 ≥85；双视口无溢出

## 验收标准

|验收 ID | 对应需求 | Given / When / Then |
|---|---|---|
| AC-001 | REQ-001 | Given 字典管理页，When 打开，Then 左侧显示类型卡片列表（11 项），点击某项高亮选中 |
| AC-002 | REQ-002 | Given 选中类型"开发类型"，When 查看右侧，Then 显示"开发类型 · 数据列表 3 项"及 3 行数据；未选时显示空态引导 |
| AC-003 | REQ-003 | Given 类型卡片，When 点击编辑，Then 编辑弹窗正常打开 |

## 追踪关系

- REQ-001→AC-001；REQ-002→AC-002；REQ-003→AC-003
