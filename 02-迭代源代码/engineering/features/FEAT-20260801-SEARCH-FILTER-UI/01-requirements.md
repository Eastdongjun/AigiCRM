# 需求规格

## 目标用户与场景

- 同事用高级筛选找案例；界面需清晰、精致、有选中反馈

## 事实

- 6 字段网格；原灰底朴素

## 假设

- 经典布局 = 白卡片+字段卡片+标题行

## 阻断问题

无

## 功能需求

| 需求 ID | 描述 | 来源 | 优先级 |
|---|---|---|---|
| REQ-001 | 高级筛选容器白卡片化（主色顶线+圆角+阴影） | 用户输入 | Must |
| REQ-002 | 字段卡片化（浅灰底+圆角+hover 微亮） | 用户输入 | Must |
| REQ-003 | 标题行：筛选条件+已选计数 tag+清空筛选按钮 | 用户输入 | Must |

## 业务规则与权限

- 无变化

## 异常与边界

- 无筛选时清空按钮禁用

## 非功能需求

- 视觉评分 ≥85；双视口

## 验收标准

|验收 ID | 对应需求 | Given / When / Then |
|---|---|---|
| AC-001 | REQ-001~002 | Given 展开高级筛选，Then 容器白底+主色顶线+12px 圆角，6 字段卡片化 |
| AC-002 | REQ-003 | Given 选择行业"化工"，Then 显示"1 项已选"tag、清空按钮激活、筛选生效（4 客户） |

## 追踪关系

- REQ-001~003→AC-001~002
