# 用户流与状态流

## 主路径

- 销售员/行政登录 → 打开新增客户页 → 页面加载部门树（大区/办事处下拉）与字典（行业/开发类型）→ 下拉可选、无权限弹窗 → 正常填写并保存客户。
- 销售员/行政登录 → 打开统计分析页 → 数据按数据范围显示（销售员=个人、行政=部门及下级）。

## 异常路径

- 未登录访问只读字典/部门接口 → 401（保持现状）。
- 无 token 或 token 失效 → 401（保持现状）。
- 字典为空：下拉为空，不弹权限错误（保持现状）。
- 数据范围过滤后无数据（如 self 用户名下无客户）：页面显示 0/空图表（前端现有容错）。

## 状态转换

- 不涉及业务对象状态转换；仅权限判断（hasAuthority → isAuthenticated）与查询过滤条件（ownerId/uploaderId 按数据范围）。
- 不可逆边界：无。

## 不适用说明

- **原因**：本功能为后端权限与数据范围修复，不涉及任何用户可见界面、布局、视觉或交互变更（ui_scope=none）。
- **受影响接口**：`GET /api/system/depts`、`GET /api/system/depts/tree`、`GET /api/system/dict/data/{code}`、`GET /api/system/dict/data/type/{id}`（鉴权放宽）；`GET /api/statistics/analysis`、`/daily-stats`、`/weekly-stats`（响应值按数据范围收窄，响应结构不变）。前端零改动。
- **验证方式**：浏览器实测页面行为（下拉可用、无弹窗、统计数值范围正确）+ 接口级断言（403/401/200）。
