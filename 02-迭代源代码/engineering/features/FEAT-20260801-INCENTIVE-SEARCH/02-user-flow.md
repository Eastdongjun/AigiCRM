# 用户流与状态流

## 主路径

1. 打开激励查询页 → 主搜索框提示"搜索客户名称 / 关键字（如：煤气管道）..."
2. 方式一：主搜索框输入客户名 → 查询 → 该客户全部案例
3. 方式二：主搜索框输入关键字（如"煤气管道"）→ 查询 → related_products 含该词的案例
4. 方式三：点"高级筛选"展开 → 产品小类选大类+小类 → 查询 → 该类目案例
5. 方式四：高级筛选 → 同事姓名输入/选择同事 → 查询 → 该同事全部案例
6. 结果卡片点击"查看详情"→ 弹窗看文件/详情

## 异常路径

- 无匹配：显示"暂无数据"
- 大类切换：小类自动清空并禁用
- 搜索接口失败：ElMessage "查询失败"

## 状态转换

- 无状态机变化；筛选参数一次性提交后端（customer-records 多参数 OR/AND 组合）
