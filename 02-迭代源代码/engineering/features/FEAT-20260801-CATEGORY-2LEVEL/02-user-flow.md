# 用户流与状态流

## 主路径
- 入口：系统设置（/system/config）→ Tab"激励类别与权限" → "激励类别管理"区块
- 查看：4 个一级类别卡片（外出参观/交流拜访/两谈两做方案/产品试点），卡片头部显示名称/编码/状态，卡片内列出该一级下的二级子项（名称/编码/分值/排序/状态）
- 折叠：点击卡片头部折叠按钮收起/展开子项列表
- 新增类别：点"新增类别"→ 弹窗（上级类别仅一级或留空）→ 保存 → 刷新
- 添加子项：一级卡片头部"子项"→ 弹窗（上级自动为该一级）→ 保存 → 子项出现在卡片内
- 编辑：一级或二级行"编辑"→ 弹窗回填 → 保存
- 删除：一级（确认含子项数，级联删子项）/ 二级（确认）→ 删除 → 刷新

## 异常路径
- 类别名称为空 → 前端提示"请输入类别名称"，不提交
- 后端拒绝三级嵌套（parentId 非顶级）→ 返回明确错误
- 删除失败 → 提示错误，列表不刷新

## 状态转换
- 类别对象：启用（status=1）↔ 禁用（status=0），仅启用类别出现在激励上传页
- 层级：一级（parentId=0）→ 二级（parentId=一级 id），最多两级
- 一级分值恒为 0，二级设置实际分值
- 不可逆边界：删除类别（含级联子项）需确认；删除前导出备份
