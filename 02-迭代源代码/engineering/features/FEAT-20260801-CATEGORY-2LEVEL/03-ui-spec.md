# UI 与交互规格

## 页面任务与信息层级
- 唯一任务：维护激励类别（一级大类 + 二级子项）
- 主动作：新增类别 / 添加子项
- 次动作：编辑 / 删除 / 折叠分组
- 阅读顺序：一级卡片（名称→状态→操作）→ 二级子项列表（名称→编码→分值→排序→状态→操作）
- 密度：卡片内表格 size=small，与系统设置页现有风格一致

## 设计系统
- 沿用系统设置页现有 Token（element-plus 默认）：主色 #409EFF、成功 #67C23A、危险 #F56C6C、文字 #606266、次要文字 #909399、边框 #e4e7ed
- 一级卡片：白底卡片（border-radius 4px，边框 #e4e7ed），头部浅灰背景（#f5f7fa）区分层级
- 一级名称：16px/600；二级表格内 14px 常规
- 间距：卡片间 12px，卡片内 padding 12px

## 组件与字段
- 一级卡片头：类别名称（16px 600）+ 编码 tag + 状态 tag + 折叠箭头 + 操作按钮（编辑/子项/删除）
- 二级子项表格：名称 / 编码 / 分值（>0 显示"X分"，否则 —）/ 排序 / 状态 tag / 操作（编辑/删除）
- 新增/编辑弹窗：沿用现有 el-dialog（上级类别 el-tree-select 仅映射一级类别 + 留空为一级；名称/编码/分值/排序/状态）
- 权限：canEdit 控制编辑与子项按钮，canDelete 控制删除（沿用现有 permList 逻辑）
- 数据来源：getCategoryTree()（现有接口，返回树）

## 状态矩阵
- 折叠：展开（默认，default-expand-all 行为）↔ 收起，箭头旋转
- 空子项：卡片内显示"暂无子项"（el-empty 小尺寸）
- 禁用类别：状态 tag danger（沿用）
- 加载：现有 loading 约定（无骨架屏，数据快）
- 错误：请求失败静默（沿用现有 catch 不提示模式）→ 本次改为 ElMessage.error 提示

## 响应式与可访问性
- 视口：1440x900 与 1280x720 验证
- 溢出：区块整体在 Tab 内滚动（沿用 max-height 360 或改为整页滚动，验证无横向溢出）
- 焦点/键盘：沿用 element-plus 默认
- 对比度：文字 #606266 on #fff ≥ 4.5:1；灰底标题 #606266 on #f5f7fa 可读
