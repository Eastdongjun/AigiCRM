# 用户流与状态流

## 主路径

1. 用户打开激励上传页（/incentive/index.vue）→ 顶部四区 Tab 按 产品试点→两谈两做方案→交流拜访→外出参观 排列，默认选中"产品试点"
2. 点击任意 Tab → 右侧表格按该区加载记录（记录内排序维持 code 权重 + 时间倒序不变）
3. 打开"上传文件"弹窗 → "选择子项上传文件"分组按四区新顺序展示
4. 系统设置 → 激励类别与权限 → 类别管理 → 一级卡片分组按四区新顺序展示

## 异常路径

- 未知/新增顶层类别（code 非四区）：sort_order 最大 → 自然排最后，与现有逻辑一致
- 无数据：分组/表格空态展示不变

## 状态转换

- 无状态机变化；仅展示顺序变化，数据归属与统计不变
