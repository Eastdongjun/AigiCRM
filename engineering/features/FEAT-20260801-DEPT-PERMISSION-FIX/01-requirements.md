# 需求规格

## 目标用户与场景

- 销售员/行政打开新增客户、客户列表/详情、激励上传、公海池、提醒等业务页面不出现 403

## 事实

- 部门列表是业务基础数据（新增客户"所属大区/办事处"下拉、激励页行业字典等）；7+ 业务页面加载依赖 /system/depts

## 假设

- 授予 system:dept:view 即修复（部门数据只读，无越权风险）

## 阻断问题

无

## 功能需求

| 需求 ID | 描述 | 来源 | 优先级 |
|---|---|---|---|
| REQ-001 | 行政（role 9）/销售员（role 11）授予 system:dept:view | 用户输入 | Must |

## 业务规则与权限

- 部门数据只读（无 dept:edit 授予，防越权修改）

## 异常与边界

- 无

## 非功能需求

- 无

## 验收标准

|验收 ID | 对应需求 | Given / When / Then |
|---|---|---|
| AC-001 | REQ-001 | Given 王磊磊（role 11），When 调 /system/depts，Then 200（修复前 403） |
| AC-002 | REQ-001 | Given 王磊磊登录，When 打开新增客户/客户列表/详情/激励/公海/提醒/学分排行/文件/审批 9 页，Then 无任何 403 |

## 追踪关系

- REQ-001→AC-001~002
