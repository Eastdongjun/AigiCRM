# UI 与交互规格

## 不适用说明

- 本功能为后端权限与数据范围修复，无新增/修改 UI。
- 页面表现期望（验收即页面行为）：
  - 新增客户页：行业/开发类型/大区/办事处下拉正常加载；无「没有访问权限，请联系管理员授权」弹窗；控制台无 403。
  - 统计分析页：销售员见个人数据；行政见部门及下级数据；管理员见全量（与修复前一致）。
- 前端代码零改动；响应结构零变化。

## 状态矩阵

| 页面/场景 | 修复前（销售员） | 修复后（销售员） |
|---|---|---|
| 新增客户页 | 弹「没有访问权限」+ 下拉为空 | 无弹窗、下拉正常 |
| 统计分析页 | 可见全公司数据（越权） | 仅个人数据 |
| 客户列表/详情/激励/公海 | 部分下拉空白/报错 | 下拉正常 |

## 视觉验证

- 不适用（无视觉变更）。最终以浏览器实测截图 + 控制台零 403 作为页面级证据。
