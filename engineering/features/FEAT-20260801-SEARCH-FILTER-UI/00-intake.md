# 功能受理

## 用户目标

激励查询页高级筛选区域 UI 美化（"好看 合理 经典布局"）。

## 当前行为

- 高级筛选为灰底（#f8f9fb）平铺网格：6 个字段（同事姓名/产品小类/行业/开发类型/日期/组织），无标题、无选中反馈、无清空入口

## 范围

- search.vue：高级筛选容器白卡片化（主色顶线+阴影）；字段卡片化（浅灰底圆角+hover 微亮）；新增"筛选条件"标题行（图标+已选计数 tag+清空筛选按钮）；标签图标主题色

## 不在范围

- 筛选逻辑（零改动）；其他区域

## 来源与事实

- 用户输入："这个高级筛选的内容UI 能在美化一下"
- 基线截图 evidence/ui-baseline-1440x900.png

## 约束

- 测试服；纯样式+少量模板

## 初始风险

- 低
