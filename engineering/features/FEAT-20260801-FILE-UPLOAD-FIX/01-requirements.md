# 需求规格

## 目标用户与场景

- 管理员/员工在文件管理页上传文件（公共/私人），上传成功要有反馈、失败要能看出原因

## 事实

- 400 根因：folderId=null 字符串；on-success 不触发根因：el-upload 内部 getFile 找不到文件（fileList 交互问题）

## 假设

- 自定义上传（参照激励页模式）可在文件页可靠工作

## 阻断问题

无

## 功能需求

| 需求 ID | 描述 | 来源 | 优先级 |
|---|---|---|---|
| REQ-001 | 未选文件夹上传不再 400（folderId null 不携带） | 实测 | Must |
| REQ-002 | 上传成功后：提示"上传成功 N 个"、弹窗关闭、列表刷新 | 用户输入 | Must |
| REQ-003 | 上传失败显示失败文件明细（成功 N 失败 M） | 用户输入 | Must |
| REQ-004 | 保持拖拽/多选/公共私人 scope 交互 | 用户输入 | Must |

## 业务规则与权限

- scope 随当前 Tab（public/private）；folderId 有值才携带

## 异常与边界

- 无文件时"开始上传"禁用；弹窗关闭清理待传列表；多文件部分失败提示明细

## 非功能需求

- 与原 UI 视觉一致（拖拽虚线区）

## 验收标准

|验收 ID | 对应需求 | Given / When / Then |
|---|---|---|
| AC-001 | REQ-001 | Given 未选文件夹，When 上传文件，Then 请求不含 folderId 且返回 200 |
| AC-002 | REQ-002 | Given 选择文件点开始上传，When 上传成功，Then 提示"上传成功 N 个文件"、弹窗关闭、列表出现新文件 |
| AC-003 | REQ-003 | When 上传失败，Then 提示"成功 N 失败 M（文件名）" |
| AC-004 | REQ-004 | Given 拖拽/选择多文件，When 上传，Then 全部上传且待传列表正确显示 |

## 追踪关系

- REQ-001~004 → AC-001~004
