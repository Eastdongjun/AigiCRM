# 用户流与状态流

## 主路径

**上传激励文件**：激励上传页 → 选 Tab（四区）与子项 → "上传文件" → 弹窗（关联客户必填 → 行业 → 相关产品两级下拉 → 按品类分支的安装详情/安装文件/跟踪记录 → 共享开关）→ 提交 → 列表刷新（四区排序）

**追加文件**：列表行"追加" → 弹窗回填（客户/行业/相关产品两级拆分/文件 _existing 标记）→ 保留未删文件+新文件合并提交 → 重算积分

**查询激励**：激励查询页 → 主搜索框（客户名或关键字）或高级筛选（产品小类/同事姓名等）→ 查询 → 卡片列表 → 客户详情时间线（四区排序）

## 异常路径

- 单槽品类（visit/exchange/plan）文件数 0 → 提交按钮禁用
- 相关产品历史值无横杠 → 大类空、小类=原值
- 单槽第 6 个文件 → 添加入口消失（5/5 封顶）
- 查询无匹配 → "暂无数据"
- 关键字为空 → 全量结果

## 状态转换

- 弹窗品类分支：pendingChild 的 categoryCode（自身或父级）∈ {visit, exchange, plan} → 单槽模式；trial → 三槽模式
- 追加回填：单槽仅 filePre 槽；历史三槽数据展示保持兼容
- 数据权限：沿用 computeVisibility（admin/权限人全量；否则数据范围+分享客户）
