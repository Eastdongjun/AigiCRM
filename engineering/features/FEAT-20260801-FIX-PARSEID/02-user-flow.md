# 用户流程

## 主路径
1. 登录测试系统 → 客户管理 → 客户列表 → 点击客户行
2. 客户详情页 → 点击「四项激励」Tab
3. 在激励记录卡片中点击「安装前/安装中/安装后」阶段文件块
4. 浏览器新标签页打开 `/api/file/download/{单个id}?token=...` → 文件正常打开/下载

## 异常路径
- 修复前:点击阶段文件 → 新标签页 `/api/file/download/[152]` 或 `[149,165]` → HTTP 400 错误页(已修复)
- 阶段无文件:页面不显示该阶段块(既有逻辑)

## 状态转换
- 点击前:文件块含文件名+类型图标(🖼/🎬/📄)
- 点击后:新标签页下载 URL;文件 200 打开
