# 需求规格

## 目标用户与场景

- 角色：销售同事，查询全公司激励案例（按产品小类、同事、客户、关键字）
- 场景：打开激励查询页，用三种方式找案例；能明确感知"关键字"也可搜索

## 事实

- 三项搜索功能已实现于源码（c61acb0）：产品小类两级下拉选项=涂层类[防腐/加固/钢结构/煤气管道/其他]、防滑板类[公共区/装置区]、机封类[水泵/渣泵/介质泵]、密封类[静密封/动密封/橡胶密封]、润滑类[润滑油/润滑脂/润滑剂]；同事姓名下拉；主搜索框客户名+关键字（related_products）双匹配
- 测试服部署版与源码一致，实测三项功能正常
- 缺口：主搜索框 placeholder 仅"搜索客户名称..."，未提示可搜关键字

## 假设

- 用户浏览器缓存旧版导致看不到功能；placeholder 提示后同事可直接使用（验证方式：部署后浏览器实测 + 用户强刷）

## 阻断问题

无

## 功能需求

| 需求 ID | 描述 | 来源 | 优先级 |
|---|---|---|---|
| REQ-001 | 主搜索框 placeholder 提示支持关键字搜索："搜索客户名称 / 关键字（如：煤气管道）..." | 用户输入 | Must |
| REQ-002 | 查询页具备产品小类两级搜索（五大类×子项，选项与用户要求一致） | 用户输入 | Must |
| REQ-003 | 查询页具备同事姓名搜索（搜同事出其全部案例） | 用户输入 | Must |
| REQ-004 | 查询页具备客户名称 + 关键字搜索（客户名出该客户案例；关键字如"煤气管道"出相关案例） | 用户输入 | Must |

## 业务规则与权限

- incentive:view 权限（全员可查）；搜索范围为全员记录（共享口径）
- 产品小类筛选用 related_products LIKE 匹配，与品类树命名独立

## 异常与边界

- 搜客户名无匹配 → 空结果"暂无数据"
- 关键字无匹配 → 空结果
- 大类未选时小类下拉禁用；大类切换时清空已选小类

## 非功能需求

- 兼容性：无新增依赖；构建产物 hash 化，强刷即新
- 可观测性：证据截图 + 实测记录
