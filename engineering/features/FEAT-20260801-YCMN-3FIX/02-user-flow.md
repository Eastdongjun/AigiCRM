# 用户流与状态流

## 主路径

1. 激励上传页（/incentive）→ 左侧分类树点击子分类 → 点"上传文件"或表格行"追加" → 弹窗打开（基本信息/安装详情/文件槽位/跟踪记录/共享）→ 文件槽位首屏可见（修复后）→ 点击"+"卡片 → 系统文件选择框弹出 → 选择文件 → 卡片显示缩略图/文件名 → 可删除/继续添加 → 点"上传并提交"。
2. 公海池页（/sea）非管理员 → 列表按可见范围过滤 → 点"捞取" → 后端校验客户所在池对申请人可见 → 通过则发起审批，拒绝则提示"无权限捞取该公海池客户"。
3. 系统管理 → 用户管理 → 新增用户 → 必填项（账号/姓名/角色/手机号）留空点保存 → 表单标红提示 → 全部填写后保存成功。

## 异常路径

- ①：视口 1280x720 时弹窗内滚动仍可用；文件槽位不被底部按钮遮挡。
- ②：客户 pool_id 为 NULL（历史隐身）→ 拒绝捞取并提示；已被他人申请 → 原有"审批中"提示；admin 不受限。
- ③：编辑用户时已有数据缺手机号等 → 编辑保存不强制必填（仅新增校验）。

## 状态转换

- 公海客户：available（待捞取）→ pending_approval（已申请，审批中）→ claimed（已捞取）；拒绝时回滚为 available。
- 新增用户：草稿（表单校验失败不提交）→ 已创建（唯一性/必填通过）。
