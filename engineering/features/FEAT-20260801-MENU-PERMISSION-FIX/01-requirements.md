# 需求规格

## 目标用户与场景

- 销售员登录后菜单只显示有权限的项；点击任意菜单项不出现 403

## 事实

- 硬编码菜单中唯一无权限判断的业务项是"学分录入"（score:entry）

## 假设

- 菜单项权限判断与接口权限码一致即可消除 403

## 阻断问题

无

## 功能需求

| 需求 ID | 描述 | 来源 | 优先级 |
|---|---|---|---|
| REQ-001 | 学分录入菜单仅对 score:entry 权限者显示 | 用户输入 | Must |
| REQ-002 | 学分排行菜单仅对 score:ranking 权限者显示 | 用户输入 | Must |
| REQ-003 | 岗位管理菜单判断用 system:position:view | 审计 | Must |

## 业务规则与权限

- 前端菜单 = 权限码过滤；接口层权限不变（纵深防御）

## 异常与边界

- 直接输 URL 访问无权限页仍 403（接口层保护，符合预期）

## 非功能需求

- 无

## 验收标准

|验收 ID | 对应需求 | Given / When / Then |
|---|---|---|
| AC-001 | REQ-001 | Given 王磊磊（无 score:entry）登录，When 查看菜单，Then 无"学分录入"项，学分管理组仅显示学分排行 |
| AC-002 | REQ-003 | Given admin 登录，When 查看系统管理菜单，Then 岗位管理正常显示（admin 有 position:view） |

## 追踪关系

- REQ-001→AC-001；REQ-003→AC-002
