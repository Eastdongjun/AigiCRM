# 需求规格

## 目标用户与场景

- 销售员在激励上传弹窗同一槽位分次添加多个文件（最多 5 个）

## 事实

- 槽位追加应保留已选文件（含未上传新文件）

## 假设

- 与 track 分支行为一致

## 阻断问题

无

## 功能需求

| 需求 ID | 描述 | 来源 | 优先级 |
|---|---|---|---|
| REQ-001 | 安装槽分次选择文件时保留已有文件并追加 | 用户输入 | Must |

## 业务规则与权限

- 最多 MAX_FILES(5)；编辑回填（_existing）保留不变

## 异常与边界

- 达到 5 个后添加卡隐藏

## 非功能需求

- 无

## 验收标准

|验收 ID | 对应需求 | Given / When / Then |
|---|---|---|
| AC-001 | REQ-001 | Given 安装前槽，When 先选 1 文件再选 1 文件，Then 槽内 2 个文件共存 |

## 追踪关系

- REQ-001→AC-001
