# 功能受理

## 用户目标

激励上传同一槽位（如安装前）分两次选文件：先选 1 个，再点添加选第 2 个——**第二个文件无法上传**（实测为第二个替换第一个）。

## 当前行为

- handleFileSelected 安装槽分支：`existing = files.filter(f => f._existing)` 后拼接——新选文件无 `_existing` 标记 → filter 结果为空 → **每次选择替换掉槽内已有新文件**
- 实测复现：第一次选 upload-t → 第二次选 ui-1440x → 槽内只剩 ui-1440x（第一个消失）
- track 分支无此问题（保留全部）

## 范围

- index.vue handleFileSelected：安装槽改为保留全部已有文件再追加（与 track 一致）

## 不在范围

- 生产；后端

## 来源与事实

- 用户输入："同一种类型 安装文件 五个槽位 上传第二个文件 无法上传"
- 浏览器实测复现（两次 fileChooser 注入）+ 修复后验证（两文件共存）

## 约束

- 测试服；纯前端

## 初始风险

- 低；与其他逻辑兼容（编辑回填 _existing 保留不变）
