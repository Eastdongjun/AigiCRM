# AIGICRM UI/UX 专业设计

本技能是本项目 2026-09 多轮真实用户反馈(8 轮迭代、6→9/10)沉淀的设计体系。不是通用美学建议,是本项目已上线、已通过视觉评审的具体做法。

## 核心理念:三层骨架论(用户原话)

> "先构思页面的整体布局,大布局里面塞小布局,小布局里面塞内容"

任何页面/弹窗按此顺序设计,**先画骨架再填元素**:

```
第1层 画布   灰色 #f5f7fa(全局 .main-content),永不放内容
第2层 整体容器 白色大卡(全局 .page-shell:圆角16+双层柔影),一个页面一个
第3层 小布局  容器内的功能段(筛选条/统计卡/表格区/卡网格/分页),段间用留白或细分隔线
第4层 元素    小布局里的具体元素(标签/数字/缩略图/按钮),各归其位
```

弹窗同理:吸顶条丨概览区丨工具条丨主从内容区丨底条,段间 1px 细线 `#eef0f3`。

## 八条设计原则(每条都来自用户真实纠偏)

1. **色彩克制**:大面积永远中性(白/灰阶/深灰文字),彩色只出现在:色点(品类)、得分数字、未读红点、单一强调蓝 #2563eb。禁止彩色底的大信息卡(用户:"看着不够高级")。
2. **细线可用,粗线禁用**:分隔用 1px `#eef0f3`/`#f1f3f6`(账本风);禁止 3px 彩色顶线、粗描边卡片、双线堆叠。灰底+多层浮层投影的叠卡风用户判定"越做越丑",已弃用。
3. **排版即层级**:大数字 28-40px/800 + tabular-nums;标签 11-12px 大写间距 `letter-spacing:1px` 灰阶;正文 14.5px/1.85。字号对比 > 颜色对比。
4. **元信息静默化**:标签灰 `#9ca3af` + 值深 `#374151` 的文字行,禁用底色药丸堆砌;品类用 7px 色点+中性文字,不用彩色药丸。
5. **尺寸统一**:同类卡片等高(grid stretch + min-height);缩略图固定正方形 1:1 四格;详情块定高(正文 min-height、附件一行 min-height),超出才允许撑高。
6. **主从骨架**:多组数据(月份/分类)用左窄栏时间轴导航(竖线+圆点节点+未读徽标)+右内容卡,点击切换;不要无限长列表一次铺完。
7. **动态点缀**:数字滚动动画(rAF 800ms ease-out)、hover 抬升 2px+柔影、选中节点蓝点扩散环。动效只做点缀,不做装饰堆砌。
8. **完成即验证**:改完必须走"截图→视觉评审→DOM 几何断言"闭环,不接受"我觉得好看"。

## 标准工作流

1. **构思**:白板画出三层骨架(画布/容器/小布局/元素),列出每层内容物——不画完不写代码。
2. **取令牌**:读 `references/tokens-and-patterns.md`,直接复用已验证的 CSS 模式(page-shell/账本弹窗/主从骨架/时间轴节点/Bento统计卡/静默元信息/分割线)。缺的才新造,新造的写回该文件。
3. **实现**:单文件改动优先;Element Plus 组件按该文件里的 `:deep()` 覆写套路处理,不自造组件。
4. **验证**:按 `references/visual-review-loop.md` 执行——build→部署测试环境→browser-use 截图→视觉模型评审(明确告诉它设计意图,让它逐项核验)→DOM 几何断言(等高/宽度/对齐用 evaluate 量,不靠肉眼)→不达标回 3。
5. **归档**:截图与评审结论存项目执行目录 evidence,提交信息写明设计变更。

## 何时读参考文件

- 写任何 CSS 前 → `references/tokens-and-patterns.md`(全部是本项目已上线的模式,含设计令牌表)
- 交付验证前 → `references/visual-review-loop.md`(browser-use 具体操作序列与已知坑:渲染器卡死重建页签、evaluate TDZ、截图超时重试)

## 反模式清单(出现即返工)

- 彩色底大卡 / 多色药丸标签阵列 / 3px 彩色顶线
- 灰画布上叠多层白浮层卡(2026-09-20 用户否决)
- 全部内容单列长滚动无导航
- 同类卡片高度/宽度不一、缩略图随数量变宽
- 只改 CSS 不做视觉验证就声称完成
- 为了"去线条"连必要的结构分隔也去掉(用户后来明确要求分页上加浅色横线)
