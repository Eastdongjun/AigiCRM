## 一、实现

### 1. `FileGrantService`

- `folderAncestors(folderId)`：沿 `biz_file_folder.parent_id` 向上，包含自身；`parent_id=0/null`、`deleted=1`（`selectById` 过滤）、环（visited）立即停止，最多 50 层。
- `orgAncestors(orgId)`：`sys_org_closure` 查 `ancestor_id`，加自身；闭包不可用/异常只返回自身（fail-closed，不放大）。
- `coversFile`：
  - `FOLDER` 授权 `inherit=1` 且 `object_id ∈ folderAncestors(file.folder_id)` → 命中；
  - `inherit=0` 不对文件生效；
  - `FILE` 仍按 file id；
  - `SPACE` 仍按 `scope_level`（A2 将切 `space_type`）。
- `coversFolder`：
  - 目标夹自身 → 命中（不限 inherit）；
  - 父夹且 `inherit=1` → 命中。
- `scopeOrgCovers`：`scope_org_id` 为空不限；否则目标 org 的闭包祖先集包含该 scope。
- `decideFiles(Collection<BizFile>, action, userId)`：
  - 一次 `load` grants；
  - `orgCache/folderCache` 按 id 记忆化；
  - DENY 直接终止该文件循环，ALLOW 记录；返回 `Map<fileId, Decision>`。
- `decideFile` 委托 `decideFiles`，单文件路径同样受益。

### 2. `FolderPermissionService.permsForFiles`

- 循环前调用 `fileGrantService.decideFiles(files, P_VIEW, userId)`；
- 每行只查 map 的 DENY，不再逐文件调用 `decideFile`；
- 行级 `perms`/DENY 隐藏与批量预载同源。

### 3. 测试

`FileGrantServiceTest` 新增：

- `folderGrantRecursesToChildFolders`：父夹 A → 子夹 B → 文件；`inherit=1` ALLOW，`inherit=0` ABSTAIN；
- `scopeOrgUsesSubtreeAncestors`：文件 org=11、闭包 10→11、scopeOrg=10 → ALLOW；
- `decideFilesLoadsGrantsOnceForPage`：两文件一次 `selectList`（Mockito `times(1)`）；
- 既有 DENY 优先、过期、非继承、SPACE、角色主体测试保持。
