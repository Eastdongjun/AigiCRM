## 三、体系化建议（按落地顺序）

1. **发布级验收清单（一次性固化，每发布必走）**：代码门禁 → API 实测 → **PC 浏览器逐页逐 tab** → MP 真机清单 → 文案走查 → 生产 L5。落成 out/ 模板+scripts 可勾选件。
2. **跨层一致性对账表**：多端功能变更时强制四行对账（PC 模板/PC 逻辑层/MP js/MP wxml+后端），folder 案例的教训产品化。
3. **MP 发布通道固化**：请用户在小程序后台"开发设置"生成上传密钥交配置 → cli upload 自动化 → 否则每次手动（本次已卡一天）。**建议立刻做。**
4. **债务清偿排期**（功能线降温后一批处理）：bugs=41、S1068×40、S6582×10、文件模块操作日志空白、deleteFile module 归属 P3、回收站 03:30 终验。
5. **多窗口治理**：现状已稳（单一实施窗+QC 广播接管）；维持。
