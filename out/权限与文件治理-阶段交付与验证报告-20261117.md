## 三、安全审查（本次新增面）

| 检查 | 结果 |
|---|---|
| 法布施删除默认权限 | 05/06 无 `fabushi:file:delete`；TY010 实测 403；admin 绑定后才 200 |
| 跨 scope 删除 | `deleteFile` 按 `file_scope` 分派；public/private/incentive 分支未放宽；fabushi 只认新码 |
| 客户唯一 SQL | 使用 MyBatis `LambdaQueryWrapper` 参数绑定，无字符串拼接注入 |
| 客户名称归一化 | NFKC/括号/空格/大小写；SQL 回填脚本做 SQL 转义；无硬编码人员/角色 |
| 版本回滚 | 控制器 `hasAnyAuthority('file:edit','file:version:rollback')`；对象级 `checkFile(P_REPLACE)` 仍在 |
| 迁移 | 列/表/索引/权限登记，无数据删除；历史同名客户保留 |
| 生产 | 未写入/未部署/未清理；测试服已还原 |

**残余安全风险（必须知晓）：**
1. 法布施文件当前是**公司级可见**（`file:view` 即可见 17 条）；按大区/办事处/部门/个人收窄的 `fabushi|file_view` 数据范围**尚未接入**。
2. 版本回滚的非 admin **数据范围**未接入；当前授权角色仍受对象级 `file:edit` 约束，不能只靠新码回滚任意文件。
3. 统一 `biz_file_grant`/`biz_file_link`/`biz_recycle_bin` 只是建表，**尚未替换**现有 ACL/类型默认/回收站服务。
4. 缩略图/5 秒视频/200MB 断点续传/秒传/病毒扫描**未实现**。
5. 离职交接、组织移动、激励/任务回收站**未实现**（仅设计/字段）。
6. 生产客户名称唯一必须先跑 `backfill-customer-name-norm.py`；只跑迁移会漏全角括号旧名。
