## 4. 回滚

- **应用**：回滚后端 jar + PC dist + MP 版本即可；旧前端对新表/新列无依赖（新增列均有默认值）。
- **DB**：迁移为增量（新表/新列），**默认不回滚 DDL**；如需回滚：
  - `.4`：`DROP TABLE biz_fabushi_bookmark; ALTER TABLE biz_fabushi_book DROP COLUMN layout_type;`
  - `.3`：`DROP TABLE biz_fabushi_shelf_group; ALTER TABLE biz_fabushi_shelf DROP COLUMN pinned, DROP COLUMN sort_no, DROP COLUMN group_id, DROP COLUMN finished_at;`
  - `.2`：`DROP TABLE biz_fabushi_recitation;`
  - `.1`：类型重映射需按 Q3 反向脚本单独评审，**不建议窗口内回滚**。
  - `.6`–`.9`（2026-11-24 补充）：只改数据、不改表结构——行业词表补默认值、首启向导标记、菜单改名、菜单移动。默认不回滚；`.8`/`.9` 若必须回退，是把菜单名和父组改回去，需单独评审。
